# influencer-market-analysis

## 1. Problem Statement
To analyze social media influencer marketing trends, engagement rates, influencer tiers, and business impact using data analysis and visualization.

## 2. Dataset Source and Description
**Source:** [Statista – Global Influencer Market Size](https://www.statista.com/statistics/1092819/global-influencer-market-size/)

The project uses an Excel dataset containing information about market spending, social platform engagement, content formats, influencer tiers, and business impact indicators.

## 3. Steps Followed
- **Data Collection:** Uploaded and imported the Excel dataset using Pandas.
- **Data Cleaning:** Removed duplicate rows, trimmed extra spaces, converted values to numeric format, and corrected fractional engagement percentages.
- **Data Analysis:** Examined market spending, platform engagement, content formats, influencer tiers, and business impact.
- **Data Visualization:** Created line charts and bar charts using Matplotlib and Seaborn.
- **Summary:** Displayed dataset statistics and record counts by category.

## 4. Key Findings
- Global influencer marketing spending trends can be examined from 2021 to 2026.
- Engagement rates can be compared across social media platforms and content formats.
- Nano, Micro, Macro, and Mega influencer tiers can be compared using illustrative engagement estimates.
- Business impact indicators help explain the reported benefits of influencer marketing.


## 5. How to Run the Project
1. Open Google Colab.
2. Upload the Python notebook or copy the project code.
3. Install the required libraries if needed:

   ```bash
   pip install pandas matplotlib seaborn openpyxl
   ```

4. Run the code and upload the Excel dataset when prompted.
5. Ensure the Excel file contains a sheet named `Cleaned data`.
6. View the generated charts and summary statistics.
